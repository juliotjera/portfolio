À propos

About Me

Disponible dès décembre 2026

Salut, je suis Juliot JERA — étudiant en 3ᵉ année de Licence Informatique à l'ESMIA INNOVATION, à Antananarivo. Je construis des applications web de bout en bout, de l'interface jusqu'à la base de données.

Côté interface, je travaille avec HTML, CSS, JavaScript et React.js. Côté serveur, avec Node.js, Java (Spring Boot) et JSP, sur PostgreSQL ou MySQL. J'ai aussi pratiqué le C, Python et le PHP natif, ce qui m'a solidifié les bases côté algorithmique.

Mon projet le plus abouti est Tanàna Madio, une plateforme de gestion des déchets urbains : application web full-stack doublée d'une version mobile, avec optimisation des tournées de collecte. Je recherche un stage de 6 mois à partir de décembre 2026, en front-end, back-end ou full-stack.
